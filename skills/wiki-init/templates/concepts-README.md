# Concepts — cross-cutting concepts

Pages about aspects that touch **several modules** and so do not fit on one module page. **Created on demand**, when a concept is actually worked out in code or established by a finding.

To create one: add `<concept>.md`, a line in [../index.md](../index.md) and an entry in [../log.md](../log.md); link it from the relevant module pages as `[[concepts/<concept>]]`.

A concept is a candidate when a topic is mentioned on two or more pages and has no page of its own (`wiki-lint` lists these).
